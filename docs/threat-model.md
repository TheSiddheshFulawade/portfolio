# Threat model

STRIDE model of what exists on `develop` at `a56cd6e` (2026-11-24). Every file named here was read for this review.
Update it whenever a spec adds an endpoint, a third party or a data store (`.claude/skills/security-baseline/SKILL.md`).

**Scope**: static site on Cloudflare Pages, content build, `/api/visits` Function and D1, GitHub Actions.
Development tooling is out of scope. The Settlement Lab API has its own repo and needs its own model.
**What we protect**: what visitors are served, visitor privacy, private and employer information, the salt and account
logins, the integrity of `main`, and the zero-cost limits. There are no user accounts, cookies or payments.
**Trust boundaries**: browser to Cloudflare edge · edge to Function · Function to D1 · pull request to CI ·
GitHub to the Cloudflare build.

STRIDE letters: S spoofing · T tampering · R repudiation · I information disclosure · D denial of service · E elevation
of privilege. **[NV]** means "not verified from the repo" (dashboard, account or GitHub setting, or live behaviour).
Paths starting with `scripts/emit-`, `scripts/build-`, `server/`, `functions/`, `migrations/`, `src/`, `public/` and `e2e/`
are inside `apps/web/`.

| V1  | Counter value: fake visits             | S, T    | Same-origin check on POST, exact host list (`server/visits/handler.ts`); one count per IP per day, IPv6 cut to /64, user agent ignored (`visitor-hash.ts`) | An `Origin` header is not authentication outside a browser. | V3  | D1 and salt reached from a preview     | T, I, E | Host list stops preview writes in reviewed code (`handler.ts`)                                                                                             | Preview builds run branch code, which can ignore that list. D1 and salt must be bound to Production only; binding scope is [NV]                                                                                                                             | User: check the scope at setup (V11-05)                           |
| V4  | Request flood                          | D       | None in code. The WAF rate rule on `/api/*` is planned (spec 003) and not configured yet                                                                   | A zone rule does not cover `pages.dev` hostnames. Off-list hosts still cost a D1 read                                                                                                                                                                       | User: add the rule. Web: answer off-list hosts without a read     |
| V5  | D1 free daily quota                    | D       | A known visitor causes no write (`visit-store.ts`); failure gives 503 and the footer shows nothing (`visitor-counter.component.ts`)                        | `readTotals` reads one more row per day. Each new visitor also recounts all of today's rows, so reads grow with the square of daily visitors; a few thousand in a day could use the quota. The counter then hides until 00:00 UTC; pages are unaffected     | Web: keep one running total and increment it, before busy traffic |
| V6  | Visitor privacy                        | I       | Only a salted daily hash is stored; no IP, user agent or log line (`visitor-hash.ts`, `handler.ts`, `migrations/0001_visits.sql`)                          | Anyone holding both the salt and the rows could test IPv4 addresses against the hashes. Old rows are deleted only when a new visitor arrives, and D1 keeps restorable history for 7 days on the free plan (Cloudflare docs). Cloudflare's own logs are [NV] | User: long random salt, Production only, replace it if exposed    |
| V7  | Database and internals through the API | T, I, E | Bound SQL parameters, no request body read (`visit-store.ts`); generic RFC 9457 errors; no CORS header (`handler.ts`)                                      | `_headers` does not apply to Functions: responses carry nosniff, CORP and no-store only. The local stub adds the full set (`e2e/serve.mjs`), so the smoke test cannot show this                                                                             | Web: low, add HSTS in `handler.ts`                                |
| V8  | Abuse cannot be traced                 | R       | Deliberate: no logging (`handler.ts`)                                                                                                                      | No evidence after an abuse event                                                                                                                                                                                                                            | Accepted for privacy                                              |
